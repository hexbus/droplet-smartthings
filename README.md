# Droplet SmartThings

An unofficial SmartThings Edge integration for Hydrific Droplet using MQTT.

## Status

Initial project setup. No driver implementation is included yet.

Planned data path: Hydrific Droplet → MQTT broker → SmartThings Edge driver.

## Development prerequisites

- A SmartThings hub with Edge and LAN support
- SmartThings CLI with authenticated account access
- An MQTT broker reachable by Droplet and the hub
- Verified Droplet MQTT topics and sample payloads

## Driver channel

A development channel named **Hydrific Droplet** has been created in SmartThings using the published [terms of use](https://github.com/hexbus/droplet-smartthings/blob/main/TERMS.md). No sharing invitation has been created. Hub enrollment and driver installation are pending.
